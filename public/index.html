            01 / FULL-STACK DELIVERY
            
CoreRunner

            Live interactive demo
          

          

            
One delivery. A connected full-stack system.

            
A fictional Atlanta courier service connects React customer, dispatcher, and courier interfaces to a JavaScript API. Server-side validation manages quotes, assignments, handoffs, and delivery status.

            

  
Languages
JavaScript · SQL

  
Frontend
React · HTML · CSS · Vite

  
Backend
Node.js · Express

  
Databases
PostgreSQL / Neon (hosted) · SQLite (local)

  
Testing
Playwright · Node.js test runner



            

              
Engineering focus
SQL-backed persistence, expiring quotes, courier-scoped workflows, and PIN, signature, or photo proof. Separate storage adapters support local development and isolated hosted demo workspaces.

              
Explore the project
The hosted demo connects booking, dispatch, and courier workflows. Email, payments, and route positions are simulated; use sample information only.

            03 / FULL-STACK HOME CARE
            
Proverbs 31 Cleaning

            Portfolio demo · full-stack source
          

          

            
Thoughtful care. Database-backed workflows.

            
A cinematic home-care experience pairs HTML, CSS, and vanilla JavaScript with a Node.js API and Supabase. The source includes customer and owner workflows, relational booking data, and server-controlled pricing and scheduling.

            

  
Languages
JavaScript · SQL / PLpgSQL

  
Frontend
HTML · CSS · Vanilla JavaScript

  
Backend
Node.js · Vercel Functions · Supabase

  
Database
PostgreSQL (Supabase)

  
Auth & storage
Supabase Auth · Supabase Storage

  
Testing
Node.js test runner



            

              
Engineering focus
Relational schema migrations and SQL functions model bookings, quote snapshots, and scheduling rules. API authorization separates customer and owner access, with private storage for walkthrough media.

              
Explore the project
The portfolio preview demonstrates service selection and customer flows with simulated accounts, availability, emails, and payments. The full-stack source is separate from which integrations are enabled in the preview.

04 / DATING & FRIENDSHIP
LuvSparq
Live website · App in development

          

            
A little time. A real spark.

            
LuvSparq brings dating, friendship, and social discovery into one experience, with an Atlanta pilot planned. Its flagship LuvSpeed flow gives participants four-minute conversations followed by a 25-second cooldown to connect or pass.

            
The Flutter frontend explores onboarding, separate Dating and Friends modes, LuvSwipe, interactive discovery, chats, private activity, and simulated LuvSpeed event flows. Backend integration and real-time services are still planned; the prototype does not represent a live dating service.

            
Mobile frontend
Dart · Flutter
Public website
HTML · CSS · JavaScript · Vercel
Website experience
Animated logo intro with reduced-motion support, once-per-visit playback, and an interactive onboarding tour
